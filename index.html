1
新增流程 → 觸發器
新增「即時雲端流程」，觸發器選 當收到 HTTP 要求時，儲存後複製 HTTP POST URL。
2
傳來的 JSON 格式
undoneList 只含未交的人，每人都帶 email 欄位：
{ "surveyName": "115(一) 公關用書", "undoneList": [ { "type":"國小", "district":"北二區", "manager":"鄧克強", "email":"teng@co.com", "missing":["國小提報表"] } ] }
3
加「套用至每一個」迴圈
來源選 triggerBody()?['undoneList']，對每個未交者各執行一次。
4
迴圈內：Outlook 寄信 ＋ Teams 訊息

email

type 國小/國中
